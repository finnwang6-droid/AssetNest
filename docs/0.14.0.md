# 0.14.0：智能文件夹、视频封面与鼠标框选

智能文件夹通过左侧「＋」新增，右侧「⋯」编辑或删除。可组合任一项 / 全部、满足 / 不满足，以及最多四层条件组；输入后显示实时匹配数量。规则保存到本地索引，修改素材后查询结果自动更新，不会移动原件。旧版筛选条件继续兼容。

支持名称、格式、标签、文件夹、文件夹名、文件名、颜色、添加/修改/创建日期、链接、注释、宽度、高度、文件大小、形状、评分、标注和时长。数值单位为像素、字节和秒；日期按本机日历包含整天，未记录的日期和时长不伪造。颜色使用已有色板、RGB 距离 80；标注对应已有星级是否大于零。正则支持基础表达式、字符集及一个重复符号，不支持分组、回溯引用或多个重复符号，避免复杂规则阻塞查询。

视频在可见缩略图进入视口时串行生成 PNG 封面；使用浏览器自身支持的解码器，截取靠近开头的画面，缓存按内容哈希保存。原视频字节不改动。同步缓存尺寸和时长，供属性面板和智能规则查询。列表缩略图、右侧预览和打开后的播放器均支持悬停静音播放，移开暂停/释放播放资源。

不支持的编码显示可重试提示，原件仍可下载并用本地播放器打开。封面生成限制为 256 MB、25 秒读取等待，后台预览暂停时不会生成。缓存遵循现有容量与清理规则；Eagle 原库的封面缓存与技术信息保存在拾素材支持目录。

列表空白处拖动可框选多项，Ctrl 切换选择，Shift 增选，Alt 减选，Esc 取消本次框选并恢复原选择，拖近边缘自动滚动。保留从素材卡片开始拖出原文件、键盘选择和批量操作。单张图片工具栏增加「框选放大」，拖动区域后适配放大，Esc 取消框选，双击图片或「适应」恢复画面。区域注释仍从现有注释按钮进入，原图不裁切。

同时包含统一预览高度并铺满完整行、恢复本地 PNG 图标库、分组菜单、简化素材库切换入口、隐藏底部库路径。

验证：177 项自动测试；隔离 Edge 中使用原创图形和真实录制的 WebM，检查视频封面与时长缓存、三处静音悬停、规则实时计数/保存/动态更新、嵌套组、拖选、框选放大与恢复。测试入口：`node tools/smart-media-browser-check.mjs`。
