# AssetNest 0.10.2：拖出原文件

Windows 桌面版现在支持直接从素材网格拖出原文件。可单张拖动，也可先用 Ctrl / Shift 多选，再拖动选中的素材。目标程序需要支持 Windows 文件拖放；图片显示为图片还是附件，以及是否需要确认发送，由目标程序决定。浏览器版保留原有的应用内拖拽，不提供原生跨软件文件拖出。

## 实现与使用

- 使用 Windows 标准 `CF_HDROP` / `FileDrop` 传递原文件列表，不再只携带应用内素材编号，也不把缩略图当作原件。
- 仅允许复制，目标程序不能通过本次拖拽移动素材库中的原件。不修改剪贴板，不自动发送聊天消息。
- 应用内拖到左侧文件夹仍可归类，保留已有文件夹归属。拖到空白区域或按 Escape 取消，不进行归类。
- 一次最多 500 个素材。缺失原件、失效素材库或处理失败会提示错误，不返回部分文件列表。
- 网页消息只提供素材编号；原文件路径由本机服务从当前素材库索引解析。接口要求桌面模式、连接密钥和素材库标识，并拒绝扩展来源。

需要安装新版桌面程序才能使用。此版本包含 0.10.1 的属性栏、PDF 封面和监控文件夹功能。

## 验证

公开版 140 项回归测试通过，包含多选拖拽数据、错误与取消后的状态清理、切库保护、浏览器回退、缺失原件与请求鉴权。独立桌面测试验证了原生文件接收窗口可得到 `FileDrop`、操作结果为 `Copy`，接收文件与原件哈希一致；应用内拖到文件夹归类成功。
