# AssetNest 0.10.1

发布日期：2026-10-21。Windows x64，浏览器采集扩展继续使用 0.5.5。

## 属性栏与 PDF 封面

- 网格单击和大图预览共用属性栏：缩略图、色板、名称、注释、来源、标签、文件夹、评分和基本信息。
- 标签与文件夹支持搜索选择、逐项移除和多文件夹归属；标签可输入并回车创建，选择面板支持键盘操作。
- 直接点击星级评分；再次点击当前星级可清除。名称、注释和来源网址自动保存并显示结果。
- 来源地址仅接受安全 HTTP/HTTPS 地址，可打开原网页；色板可复制颜色，导出按钮下载原文件。
- 基本信息增加修改日期，缺失日期显示“—”。属性栏适配窄窗口，选择面板保持在视口内。
- 可见 PDF 在客户端通过随包 PDF.js 逐个生成首页封面，列表与属性栏共用缓存，双击仍可分页阅读。已有封面优先使用，不改写 PDF 或原始元数据。
- 自动 PDF 封面限制为单文件 32 MiB、任务 30 秒；损坏、加密或超限文件显示原因与重试入口。封面生成失败不表示原文件丢失；本版没有 PDF 密码输入功能。

## 包含 0.10.0 的监控文件夹功能

入口：左上角菜单 → 设置 → 任务与维护 → 监控文件夹。

配置目录后自动复制新文件到当前素材库，可设置文件夹、标签、子目录和是否导入已有文件。支持暂停、继续、错误重试和移除规则；源文件保留，移除规则不删除已入库文件。相同内容跳过，来源内容变化作为新版本保存。

监控规则按素材库隔离，切库后停止旧库监控。软件关闭时不扫描；不提供双向同步。默认约每 5 秒扫描、文件稳定至少 2 秒后处理；支持的类型及上限见[接口说明](监控文件夹接口说明.md)。直接写入 Eagle 素材库前请退出 Eagle 并备份原库。

## 公开版验证

136 项合成素材回归测试通过；三项依赖个人素材的本机用例不纳入公开测试。

独立浏览器验证了标签创建/搜索/移除、文件夹增删、评分、名称/注释/来源自动保存、原文件导出哈希、窄窗口布局、PDF 首页封面、翻页及损坏文件提示，无页面运行错误。验证使用合成图片和两页 PDF，没有访问个人素材库。

安装包从公开源码重新构建，保留原创 SVG 图标、MIT 许可证及第三方声明。安装包没有代码签名，需要系统具备 Microsoft Edge WebView2 Runtime。没有在全新 Windows 环境完成全流程验收。
