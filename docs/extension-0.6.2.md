# 浏览器扩展 0.6.2

修复“采集未提交：请刷新网页后，重新在图片上右键采集”可能涉及的两个监听问题：

- 安装、重装或重新加载扩展时，向已打开的 HTTP/HTTPS 页面补充右键位置监听。受限制或拒绝注入的标签页不会影响其他页面。
- 在 window 捕获阶段监听右键按下及 contextmenu，避免网页在 document 层拦截 contextmenu 后丢失位置。重复注入不会重复注册监听，左键不会更新位置。

不增加扩展权限。右键位置只保存在当前页面的隔离脚本环境内，不发送给其他服务。原有位置有效期、页面地址校验和点击范围检查继续生效。

验证：173 项自动测试通过；隔离 Edge 浏览器验证网页拦截 contextmenu、已打开页面补注入、链接覆盖图片、srcset、签名 URL、背景图和跨域 frame。原图字节哈希一致，空白处不会误采集邻图。

用户已登录的 Pinterest 页面因浏览器连接超时未完成实测。重新加载扩展后应显示 0.6.2；如果页面限制注入，仍需要刷新页面后再右键采集。
