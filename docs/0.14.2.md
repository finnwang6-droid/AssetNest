# 0.14.2 · GitHub 更新检测

- 启动软件后后台检查 GitHub 最新正式 Release，每天最多自动检查一次。
- 左上角菜单 →「检查更新」可随时手动检查，也可关闭自动检查或忽略某个版本。
- 发现更高版本时显示轻量提示，可查看发布说明并前往 GitHub 下载安装包。
- 版本按主版本、次版本、修订版本逐段比较；不会提示降级。草稿和预发布版不参与检查。
- 网络失败与 GitHub 限流会显示检查失败，不会误报「已是最新」。

更新来源固定为 `finnwang6-droid/AssetNest` 的 GitHub Releases API。不需要 GitHub 登录，不发送素材、素材库位置、软件连接密钥或 GitHub Token。Windows 安装版沿用系统代理设置。

发布更新时，需要创建更高版本的正式 Release，例如 `v0.14.3`，并上传 `AssetNest-Setup-0.14.3.exe`。只提交代码不会触发更新提醒。没有匹配安装包时，软件提供发布页入口。

此版本提供检测和下载入口；安装包仍由用户确认运行。0.14.2 之前的客户端需要先手动安装一次带更新检测功能的版本。
