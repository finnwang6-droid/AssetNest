# 0.14.1：本地文件夹拖入与选择交互修复

从资源管理器将文件夹拖到素材区，会创建同名文件夹并复制导入内容，保留子目录和空文件夹。拖到左侧已有文件夹时，将导入为其子文件夹。同级已存在相同名称时使用「名称 (2)」等新名称，不覆盖现有分类。也可通过菜单中的「导入本地文件夹」选择目录；浏览器的目录选择器可能不提供空文件夹，空目录保留以拖入方式为准。

先读取完整目录结构，检查限制，再创建分类并逐个导入。重复素材复用已有原件，并添加到目标分类。不会移动、改名或删除源文件。单次上限为 500 个文件夹、5000 个文件、20 层目录、总计 2 GB，单文件不超过 256 MB。跳过隐藏/系统目录和文件、可执行文件、脚本及 Windows 快捷方式；`.library` 请通过素材库管理打开。

逐个文件导入成功即保留；部分失败时显示已完成数量和失败明细，不声称整批原子提交。中途切换素材库会停止剩余导入，避免写到新库。目标分类在保存时校验；重复原件直接归类，不重复写入文件。连接失败改为可读的本地服务提示。

选择交互：从图片间隙或内容区空白处拖框；松开鼠标不会被随后产生的单击清空。普通单击只选当前项，Ctrl 单击切换增选，Shift 从固定起点选择连续范围，Ctrl+Shift 追加范围。顶部批量操作栏隐藏，右键菜单继续提供批量整理与导出。

验证：182 项自动测试通过。隔离 Chromium/Edge 使用真实本地目录拖入事件验证中文层级、空目录、超过 100 个目录条目、重复图片、重复根目录名称、拖到已有分类、目录选择器和源文件哈希不变。入口为 `node tools/directory-drop-browser-check.mjs`。
