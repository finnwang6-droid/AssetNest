# AssetNest 0.10.3：拖拽稳定性与反馈

## 改进

- 原文件检查放到后台准备，避免在本地文件检查期间阻塞桌面窗口。准备阶段可按 Escape 取消。
- 文件准备完成前已经松开鼠标，不再启动 Windows 拖放；界面提示重新拖动。
- 明确区分目标程序已接收、未接收和已取消。接收成功仅表示文件交给目标程序，不表示聊天已发送。
- 缺失原件会指出选中列表的序号和素材名；整批失败，不返回部分文件列表。
- 保留中文、空格和正常长度的长文件名；同名文件来自不同目录时都保留。仍只允许复制，不移动原件。
- 对达到 260 字符的 Windows 路径明确提示先导出到短目录，不悄悄改名、不生成缩略图替代原件，也不宣称所有接收程序都支持超长路径。
- 处理取消、重复拖拽及失败后的状态恢复；旧任务的完成消息不会清掉新任务状态。浏览器版继续使用应用内文件夹拖拽。

## 验证与兼容性记录

145 项公开版测试全部通过，包含 Windows STA 线程下真实 `DataObject` / `FileDrop` 格式、中文与长文件名、同名多选、Copy 提示、缺失原件和过长路径的整批拒绝。

使用独立安装程序和 WebView2 验证了：提前松开不启动 OLE、准备阶段取消、重复请求拒绝、缺失文件反馈、失败后可再次拖拽。无页面运行错误，测试原文件哈希不变。

QQ“我的电脑”和微信“文件传输助手”的接收行为由用户反馈测试通过，具体应用和聊天客户端版本未记录。本版自动化没有重复操作聊天窗口，也没有发送聊天消息；此反馈不代表对所有 QQ、微信版本或其他软件的兼容承诺。接收后的图片／附件形式及发送确认由目标程序决定。

## 使用

从网格拖动单张素材，或先用 Ctrl / Shift 多选再拖动。若提示目标程序未接收，请拖到其支持文件的输入区。若提示路径过长，可先将原件导出到短路径再拖动。

继承 0.10.2 的跨软件原件拖拽，以及属性栏、PDF 首页封面与监控文件夹功能。Windows x64，需 Microsoft Edge WebView2 Runtime；浏览器扩展仍为 0.5.5。
